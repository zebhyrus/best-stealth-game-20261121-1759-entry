**The Night Curator** — a top-down stealth game. You are Wren, a cat burglar in the Halden Museum of Curiosities. Three galleries, patrolling guards with vision cones, crates and display cases to hide behind, torch light and shadow pools, brass coins to throw as distractions, and one glowing artifact per floor to steal before you slip out the green exit — unseen.

- Patrols you can learn: every guard walks a fixed loop and pauses to look around
- A detection meter with a recovery chance: break line of sight and the alarm cools off
- Noise matters: running is loud, sneaking is quiet, thrown coins pull guards away
- Shadows hide you; torch light exposes you
- Synthesized sound (WebAudio, no files): footsteps, coin clinks, alarm stings

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. WASD/arrows to move, Shift to sneak, click to throw a coin.
